# Ревью: кто читает и как

Роли лежат в `.claude/agents/`. Каждая только читает и возвращает вердикт с находками
по шкале **blocker / major / minor**. Код правит автор.

## Кто читает какой диф

| что изменилось | кто читает |
|---|---|
| план задачи, до первой правки | `plan-reader` |
| любой диф | `gatekeeper` — что стало тише, что разъехалось |
| `check_allure_labels.py`, `check_allure_labels.sh` | `script-lead` и `devops-reader` |
| README | `devops-reader` |
| `tests/`, `docs/contract.md` | `tester` |

Одна правка обычно попадает в две-три строки — зовём всех.

## Правила

- **Один круг.** Блокеры чиним в этом же PR, мелочь — задачей с меткой `minor`.
  Повторный круг — только на исправленные блокеры.
- **Ноль находок — законный вердикт**, если рядом перечислено, что перемерено.
- **Ревьюеру не дают объяснение автора** — только диф, контракт и README.
- **Каждое утверждение — с доказательством:** команда и её вывод, `файл:строка`, случай
  в `tests/cases`, который краснеет при поломке.

## Что остаётся в PR

Шаблон `.github/pull_request_template.md`. Пустое поле без «неприменимо, потому что…»
значит, что ревью не закончено.
